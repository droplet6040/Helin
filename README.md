## About This Fork

**Helin** is a personal customization of [GheychiApp](https://github.com/MahdiyarGHD/GheychiApp) tailored for a minimal, air-gapped workflow. Aside from custom branding and icon artwork, this fork simply removes network and package-installation permissions along with in-app update and feedback menus so the application operates 100% offline with pre-bundled spam models.
